# SegurIA Monitor

## Português 🇧🇷

Plataforma de Monitoramento de Segurança com IA que detecta comportamentos anômalos em tempo real. Utiliza aprendizado de máquina (Isolation Forest), banco vetorial (FAISS), alertas por e-mail/WhatsApp, dashboards interativos (Streamlit) e API REST (FastAPI).

## English 🇺🇸

AI-Powered Security Monitoring Platform that detects anomalous behaviors in real time. It uses machine learning (Isolation Forest), vector database (FAISS), alerts via email/WhatsApp, interactive dashboards (Streamlit), and REST API (FastAPI).

## Español 🇪🇸

Plataforma de Monitoreo de Seguridad con IA que detecta comportamientos anómalos en tiempo real. Usa aprendizaje automático (Isolation Forest), base de datos vectorial (FAISS), alertas por correo/WhatsApp, dashboards interactivos (Streamlit) y API REST (FastAPI).
